# Wedding Event Management App
Wedding Event Management App (CS50x Final Project) – A web application for creating wedding events, inviting guests, and managing RSVPs. This app will demonstrate HTML, CSS, JavaScript & React skills learned in the course.

## Features:
- Users can create a wedding event.
- Send invitations to guests.
- Manage RSVP responses.
- View event details.

## Technologies Used:
- React
- JavaScript
- HTML
- CSS
