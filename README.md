# Wedding Event Management App
Wedding Event Management App (CS50x Final Project) – A web application for creating wedding events, inviting guests, and managing RSVPs. This app demonstrates HTML, CSS, JavaScript & React skills learned in the course.


## Features:
- **Create a wedding event:** Users can create a personalized wedding event with event details.
- **Send invitations:** Users can invite guests to their event by sending invitations.
- **Manage RSVP responses:** Guests can respond to invitations, and hosts can track RSVP statuses.
- **View event details:** Users can view details about the event, including location, time, and guest list.


## Technologies Used:
- **React** – JavaScript library for building user interfaces
- **JavaScript** – Core programming language for logic and interaction
- **HTML** – Markup language for structuring web pages
- **CSS** – Styling language to enhance the look of the application
